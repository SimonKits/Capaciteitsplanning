# Capaciteitsplanner

Een eerste versie van een Nederlandstalige website om medewerkers, contracturen, werkdagen en teams te beheren.

## Starten

Vereist Node.js 18 of hoger.

```bash
npm install
npm run dev
```

Open daarna de lokale URL die Vite toont.

## Eerste versie

- Medewerkers toevoegen, bewerken en verwijderen
- Team en functie per medewerker
- Contracturen per week
- Werkuren per dag van maandag tot en met zondag
- Zoeken en filteren op team
- Gegevens worden lokaal in de browser opgeslagen

De onderdelen Overzicht, Rooster en Capaciteit zijn momenteel placeholders. Voor gedeeld gebruik vanaf meerdere apparaten is een backend/database nodig.
